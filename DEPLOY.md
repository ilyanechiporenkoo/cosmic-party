# Деплой на Render (бесплатно, постоянная ссылка)

Что уже готово в проекте:
- `render.yaml` — описание сервиса: Node 24, сборка клиента, сборка базы вопросов из `content/raw*`, запуск сервера;
- `.gitignore` — в репозиторий не попадают `node_modules`, `dist` и `data/*.db` (база 115 МБ больше лимита GitHub, Render собирает её сам за ~30 с).

## Шаги

1. Зарегистрируйтесь на https://github.com и создайте **пустой** репозиторий (без README), например `cosmic-party`.
2. Загрузите проект в репозиторий (из папки проекта):
   ```bash
   git init
   git add .
   git commit -m "Cosmic Party"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/cosmic-party.git
   git push -u origin main
   ```
   При первом `git push` откроется окно входа в GitHub.
3. Зарегистрируйтесь на https://render.com (можно войти через GitHub).
4. В Render: **New → Blueprint** → выберите репозиторий `cosmic-party` → **Apply**.
   Render прочитает `render.yaml`, соберёт и запустит игру.
5. Через 3–5 минут появится ссылка вида **https://cosmic-party.onrender.com** — её и отправляйте друзьям.

## Особенности бесплатного тарифа

- После 15 минут без посетителей сервер засыпает; первый заход после этого открывается ~30–60 секунд.
- Статистика ответов (`data/stats.db`) сбрасывается при каждом перезапуске/деплое — редкость снова считается от популярности в Википедии.
- Обновить сайт: внесите изменения, `git commit` и `git push` — Render пересоберёт сам.
